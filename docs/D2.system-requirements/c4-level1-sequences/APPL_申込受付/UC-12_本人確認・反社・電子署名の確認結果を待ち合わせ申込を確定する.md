# UC-12: 本人確認・反社・電子署名の確認結果を待ち合わせ申込を確定する

- **事前条件**: 申込が入力完了(必須項目充足・関係者整合検証済み)で、本人確認(eKYC)・反社照合・電子署名の 3 つが各 UC により実施中または実施済み
- **事後条件**: 本人確認(eKYC)成立・反社照合の非該当確定・電子署名取得の 3 つがすべて成立した場合に、申込の業務状態が「申込確定」となり募集コンプライアンス証跡が記録される。いずれかが未成立と判明した時点で以降の確認へ進まず、停留事由を記録して申込内容確認画面に結果を返す

```mermaid
sequenceDiagram
    autonumber
    actor act1_2 as 募集人<br/>ACT-1・ACT-2
    participant sys as 個人保険新契約システム
    participant ext6 as 本人確認(eKYC)サービス<br/>EXT-6
    participant ext7 as 反社チェックサービス<br/>EXT-7
    participant ext8 as 電子署名サービス<br/>EXT-8

    act1_2->>sys: 申込内容確認画面で<br/>「申込確定」ボタンをクリック
    activate sys

    opt FUNC-13: 申込確定(確認結果待ち合わせ)機能
        Note over sys,ext8: 各確認の実施自体は UC-47(本人確認)・<br/>UC-51(反社照合)・UC-56(電子署名)で扱い、<br/>本 UC は 3 つの結果の待ち合わせと<br/>申込確定のみを扱う

        sys->>ext6: 本人確認結果(確認成否・確認日時)を照会
        activate ext6
        ext6-->>sys: 本人確認結果
        deactivate ext6

        break 本人確認が未成立・照会不達
            sys->>sys: 申込の業務状態を「確認中」のまま保持し、<br/>本人確認の未成立(または照会不達)を<br/>停留事由として記録
            sys-->>act1_2: 申込内容確認画面に本人確認が未成立である旨と<br/>本人確認の再実施導線を表示
            Note over sys: 参照: UC-13 停留申込を業務上収束させる
        end

        sys->>ext7: 反社照合結果(非該当/要確認/該当)を照会
        activate ext7
        ext7-->>sys: 反社照合結果
        deactivate ext7

        break 反社が該当・要確認・照会不達
            sys->>sys: 申込の業務状態を「確認中」のまま保持し、<br/>反社照合の判定結果を停留事由として記録
            sys-->>act1_2: 申込内容確認画面に反社確認が未了である旨と、<br/>コンプライアンス部の判断待ちである旨を表示
            Note over sys: 参照: UC-53 「要確認」を最終判断する
        end

        sys->>ext8: 電子署名の取得結果<br/>(署名者・署名日時・検証結果)を照会
        activate ext8
        ext8-->>sys: 署名済み文書・署名検証結果
        deactivate ext8

        break 電子署名が未取得・検証不成立・照会不達
            sys->>sys: 申込の業務状態を「署名待ち」のまま保持し、<br/>署名の未取得(または検証不成立)を<br/>停留事由として記録
            sys-->>act1_2: 申込内容確認画面に署名が未取得である旨と、<br/>再署名依頼の導線を表示
            Note over sys: 参照: UC-59 署名の不達・検証不成立を<br/>再署名で収束する
        end

        sys->>sys: 申込の業務状態を「申込確定」へ更新し、<br/>確定日時・3 つの確認結果・操作者を<br/>募集コンプライアンス証跡として記録
        sys-->>act1_2: 申込確定完了画面に受付番号・確定日時と、<br/>後続手続き(告知受付・第一回保険料収納)の<br/>案内を表示
        Note over sys: 参照: UC-68 業務通知を配信する
    end

    deactivate sys
```
