# UC-48: KYC の外部不達・タイムアウト時に再依頼・縮退運用で業務継続する

- **事前条件**: 外部本人確認サービスの不達・タイムアウト・応答遅延が発生し、業務状態が「依頼中」のまま滞留している
- **事後条件**: 業務上の再依頼手順により確認が再実行されるか、一定時間内に復旧しない場合は申込人へ業務通知のうえ後日再依頼として縮退運用で業務が継続された状態になる。いずれの場合も契約成立は確認成立まで保留する

```mermaid
sequenceDiagram
    autonumber
    actor act4 as 新契約事務担当者<br/>ACT-4
    participant sys as 個人保険新契約システム
    participant ext6 as 本人確認(eKYC)サービス<br/>EXT-6

    act4->>sys: KYC 滞留一覧画面で対象案件を選び<br/>「再依頼・縮退対応」ボタンをクリック
    activate sys

    opt FUNC-48: KYC不達・縮退対応機能
        sys->>ext6: 外部本人確認サービスの応答可否を確認し、<br/>可能であれば同一案件の確認を再依頼
        activate ext6
        ext6-->>sys: 再依頼の受付結果(受付/不達)
        deactivate ext6

        break 一定時間内に復旧せず再依頼を受け付けられない
            sys->>sys: 業務状態を「依頼中」のまま保持して<br/>契約成立を保留し、不達の継続時間と<br/>後日再依頼の予定を記録
            sys-->>act4: KYC 滞留詳細画面に縮退運用で業務を継続する旨と、<br/>後日再依頼の予定を表示
            Note over sys: 参照: UC-72 外部連携障害時に縮退運用する
        end

        sys->>sys: 再依頼の実行内容・再実行履歴を証跡として記録し、<br/>確認成立まで契約成立を保留する状態を維持
        sys-->>act4: KYC 滞留詳細画面に再依頼した旨と、<br/>判定結果の到着待ちである旨を表示
    end

    deactivate sys
```
