# UC-47: 取引時確認(本人特定事項)を外部サービス連携で実施する

- **事前条件**: 申込受付時に取引時確認の必要性が検知され、業務状態が「未依頼」。過去の確認結果がある場合はその有効期間が参照可能
- **事後条件**: 外部本人確認サービスの判定に依拠して業務状態が「確認成立」になる。判定が保留の場合は「要目視」、NG の場合は「確認失敗」として再依頼へ回す。有効期間内の過去結果は再利用し、高額契約は厳格な確認を要求した状態で確認を取り直す

```mermaid
sequenceDiagram
    autonumber
    actor act1_2 as 募集人<br/>ACT-1・ACT-2
    participant sys as 個人保険新契約システム
    participant ext6 as 本人確認(eKYC)サービス<br/>EXT-6

    act1_2->>sys: 本人確認画面で申込人の本人確認書類を登録し<br/>「本人確認を依頼」ボタンをクリック
    activate sys

    opt FUNC-47: 取引時確認(KYC)実施機能
        sys->>sys: 過去の確認結果の有無と有効期間、および<br/>保険料・保険金額が高額基準に該当するかを判定

        break 有効期間内の過去確認結果を再利用できる
            sys->>sys: 業務状態を「確認成立」とし、再利用した<br/>確認結果・確認日時・再利用の判断根拠を記録
            sys-->>act1_2: 本人確認画面に過去の確認結果を再利用した旨と、<br/>確認成立である旨を表示
        end

        sys->>ext6: 申込人の本人特定事項と本人確認書類、<br/>高額契約時は追加確認事項を指定して<br/>取引時確認を依頼
        activate ext6
        ext6-->>sys: 判定結果(OK/要目視/NG)と判定日時
        deactivate ext6

        break 判定が「要目視」「保留」
            sys->>sys: 業務状態を「要目視」へ更新し、<br/>目視判断の依頼を起票
            sys-->>act1_2: 本人確認画面に目視判断中である旨と、<br/>確認成立まで契約成立が保留となる旨を表示
            Note over sys: 参照: UC-49 KYC の「要目視」「保留」案件を<br/>目視判定する
        end

        break 判定が NG(書類不備・有効期限切れ 等)
            sys->>sys: 業務状態を「確認失敗」へ更新し、<br/>NG 事由と再依頼の要否を記録
            sys-->>act1_2: 本人確認画面に確認できなかった事由と、<br/>有効な書類での再依頼の導線を表示
        end

        sys->>sys: 業務状態を「確認成立」へ更新し、依頼内容・<br/>応答・確認方法・判定結果・判定日時・判定主体を<br/>証跡として保持
        sys-->>act1_2: 本人確認画面に確認が成立した旨と、<br/>以降の手続きの案内を表示
    end

    deactivate sys
```
