# UC-65: 真実性・可視性不充足/証跡消失を業務収束する

- **事前条件**: 真実性措置の付与失敗・検索要件の不備が検知されている、または保存期間内の証跡消失・破損の疑いが生じている
- **事後条件**: 要件不充足の書類は正式保存扱いとせず真実性・可視性措置が再充足されるか、消失・破損は復元により回復した状態になる。復元不能の場合はコンプライアンス部・内部監査部へエスカレーションし、影響範囲と再発防止が記録される

```mermaid
sequenceDiagram
    autonumber
    actor act16_15 as 内部監査部・コンプライアンス部<br/>ACT-16・ACT-15
    participant sys as 個人保険新契約システム

    act16_15->>sys: 証跡不備一覧画面で対象を選び<br/>「収束処理」ボタンをクリック
    activate sys

    opt FUNC-65: 証跡不備・消失収束機能
        sys->>sys: 不備の種別(真実性・可視性の不充足/<br/>消失・破損)と影響範囲を特定

        break 真実性・可視性の要件が不充足
            sys->>sys: 当該書類を正式保存扱いとせず、<br/>不充足の要件と再充足の実施内容・経緯を記録
            sys-->>act16_15: 証跡不備詳細画面に正式保存としていない旨と、<br/>再充足の進捗を表示
        end

        sys->>sys: 消失・破損範囲を特定して保全手段による<br/>復元を実施し、復元結果を記録

        break 復元不能
            sys->>sys: コンプライアンス部・内部監査部への<br/>エスカレーションを起票し、影響範囲と<br/>再発防止策を記録
            sys-->>act16_15: 証跡不備詳細画面に復元不能である旨と、<br/>影響範囲・エスカレーション状況を表示
        end

        sys-->>act16_15: 証跡不備詳細画面に復元が完了した旨と、<br/>復元範囲・実施日時を表示
    end

    deactivate sys
```
