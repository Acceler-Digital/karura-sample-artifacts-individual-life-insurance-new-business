# UC-62: 監査対象業務イベントを各工程から収集・改ざん不能に保全する

- **事前条件**: 各業務工程で監査対象業務イベント(個人情報・契約データへのアクセス/操作/参照、権限の付与・変更・剥奪、証跡参照、ログ改変試行)が発生している
- **事後条件**: 監査対象イベントが漏れなく改ざん不能な形で収集・保全された状態になる。最小権限を超えるアクセス試行と監査ログ自体への改変試行は別系統で全件追跡され、CSIRT・内部監査部へエスカレーションされる

```mermaid
sequenceDiagram
    autonumber
    actor act16_17 as 内部監査部・CSIRT<br/>ACT-16・ACT-17
    participant sys as 個人保険新契約システム

    act16_17->>sys: 監査ログ監視画面で対象期間を指定し<br/>「収集状況を確認」ボタンをクリック
    activate sys

    opt FUNC-62: 監査ログ収集・改ざん不能保全機能
        sys->>sys: 各業務工程で発生した監査対象イベントを収集し、<br/>改ざん不能な形で保全して<br/>イベント種別ごとの収集件数を集計

        break 最小権限を超えるアクセス試行を検知
            sys->>sys: 当該アクセスを拒否した記録を別系統で全件追跡し、<br/>要配慮個人情報への不正アクセス疑いとして<br/>CSIRT・コンプライアンス部へエスカレーション
            sys-->>act16_17: 監査ログ監視画面に権限超過の試行内容<br/>(試行者・対象・日時)と<br/>エスカレーション状況を表示
        end

        break 監査ログ自体への改変試行を検知
            sys->>sys: 改変試行を別系統で全件追跡し、<br/>内部監査部・CSIRT へエスカレーション
            sys-->>act16_17: 監査ログ監視画面に改変試行の内容と<br/>エスカレーション状況を表示
        end

        sys-->>act16_17: 監査ログ監視画面にイベント種別ごとの収集件数と、<br/>改ざん不能保全の状態を表示
    end

    deactivate sys
```
