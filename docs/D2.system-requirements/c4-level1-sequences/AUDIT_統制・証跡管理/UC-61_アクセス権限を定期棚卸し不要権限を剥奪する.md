# UC-61: アクセス権限を定期棚卸し不要権限を剥奪する

- **事前条件**: 定期棚卸サイクルが到来している、または人事異動・退職の連携により権限見直しの契機が発生している
- **事後条件**: 付与済み権限の妥当性が検証され、不要権限・退職者/異動者の権限が失効した状態になる。剥奪漏れによる権限残存を検知した場合は即時失効させ、残存期間中のアクセス有無を監査ログで遡及確認した記録が残る

```mermaid
sequenceDiagram
    autonumber
    actor act12 as 業務部門責任者<br/>ACT-12
    participant sys as 個人保険新契約システム

    act12->>sys: 権限棚卸画面で棚卸対象の組織・期間を指定し<br/>「棚卸を実行」ボタンをクリック
    activate sys

    opt FUNC-61: アクセス権限棚卸・剥奪機能
        sys->>sys: 付与済み権限を人事情報(在籍・所属)と突合し、<br/>職務上の必要性が失われた権限と<br/>退職者・異動者の残存権限を抽出
        sys-->>act12: 権限棚卸画面に要剥奪の権限一覧<br/>(対象者・権限・判定理由)を表示

        break 退職者・異動者の権限残存を検知
            sys->>sys: 該当権限を即時失効させ、残存期間中の<br/>アクセス有無を監査ログで遡及確認して<br/>確認結果を記録
            sys-->>act12: 権限棚卸画面に即時失効した旨と、<br/>残存期間中のアクセス有無の確認結果を表示
        end

        sys->>sys: 棚卸で不要と判定した権限を剥奪し、<br/>棚卸実施日・判定根拠・実施者を<br/>監査対象イベントとして記録
        sys-->>act12: 権限棚卸画面に棚卸が完了した旨と、<br/>剥奪件数・次回棚卸予定を表示
    end

    deactivate sys
```
