# UC-64: 証跡を説明可能な形で提供する(監査・第三者診断・監督官庁)

- **事前条件**: 内部監査・第三者セキュリティ診断・監督官庁のいずれかから証跡の請求を受領している
- **事後条件**: 請求の受領・対応期限・提供範囲の判定・回付の業務手順により、改ざんされていない証跡が説明可能な形で提供された状態になる。第三者診断の重大指摘については、是正完了がリリース判定の必須条件として記録される

```mermaid
sequenceDiagram
    autonumber
    actor act16_15 as 内部監査部・コンプライアンス部<br/>ACT-16・ACT-15
    participant sys as 個人保険新契約システム

    act16_15->>sys: 証跡提供画面で請求元(内部監査・第三者診断・<br/>監督官庁)と請求内容を入力し<br/>「提供範囲を判定」ボタンをクリック
    activate sys

    opt FUNC-64: 証跡提供機能(監査・第三者診断・監督官庁)
        sys->>sys: 請求を受領して対応期限を設定し、<br/>請求内容に対する提供範囲を判定

        break 提供範囲に含められない請求内容がある
            sys->>sys: 当該部分を提供対象から除外し、<br/>除外の理由と判定者を記録
            sys-->>act16_15: 証跡提供画面に提供できない範囲と<br/>その理由を表示
        end

        sys->>sys: 提供対象の証跡が改ざんされていないことを検証し、<br/>提供内容・提供日時・提供先を<br/>監査対象イベントとして記録

        break 第三者診断で重大指摘を受領
            sys->>sys: 指摘事項を記録し、是正完了を<br/>リリース判定の必須条件として登録
            sys-->>act16_15: 証跡提供画面に重大指摘の内容と、<br/>リリース判定に紐づけた旨を表示
        end

        sys-->>act16_15: 証跡提供画面に提供する証跡一式と、<br/>対応期限・回付先を表示
    end

    deactivate sys
```
