# UC-28: 収納不成立を再依頼・代替手段提示で収束させる

- **事前条件**: 業務状態が「収納不能」で、収納手段ごとの社内収納規程が定める再依頼回数・撤回期限が参照可能
- **事後条件**: 規程の範囲内で再依頼または代替手段による再試行が行われ業務状態が「収納依頼中」へ戻るか、期限内に成立しない場合は「収納未了撤回」として収束し、契約成立(計上)へ不成立が伝達された状態になる

```mermaid
sequenceDiagram
    autonumber
    actor act4 as 新契約事務担当者<br/>ACT-4
    participant sys as 個人保険新契約システム
    participant ext9 as 決済サービス<br/>EXT-9

    act4->>sys: 収納不能一覧画面で対象案件を選び<br/>「収束処理」ボタンをクリック
    activate sys

    opt FUNC-28: 収納不成立収束管理機能
        sys->>sys: 不成立事由・これまでの再依頼回数・<br/>撤回期限までの残日数を集約
        sys-->>act4: 収納不能詳細画面に不成立事由・再依頼回数・<br/>撤回期限と、収束方法の選択肢を表示

        break 規程の再依頼回数の範囲内で同一手段の再試行が可能
            sys->>ext9: 同一の収納手段と新たな処理識別で<br/>再依頼を発出
            activate ext9
            ext9-->>sys: 再依頼の受付結果
            deactivate ext9
            sys->>sys: 業務状態を「収納依頼中」へ戻し、<br/>再依頼回数と依頼日時を記録
            sys-->>act4: 収納不能詳細画面に再依頼した旨と、<br/>次回の成立判定予定を表示
        end

        alt 撤回期限内で代替収納手段へ変更できる
            sys-->>act4: 収納不能詳細画面に申込人へ提示する<br/>代替収納手段の候補を表示
            sys->>sys: 代替手段への変更を記録し、<br/>業務状態を「収納手段確定待ち」へ戻す
            Note over sys: 参照: UC-25 収納手段・収納金額を確定する
        else 撤回期限を超過し収納が成立しない
            sys->>sys: 業務状態を「収納未了撤回」へ更新し、<br/>撤回事由・判断者を記録して<br/>契約成立(計上)へ不成立を伝達
            sys-->>act4: 収納不能詳細画面に収納未了撤回として<br/>収束した旨を表示
        end
    end

    deactivate sys
```
