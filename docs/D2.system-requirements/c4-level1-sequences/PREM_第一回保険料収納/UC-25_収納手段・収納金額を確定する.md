# UC-25: 収納手段・収納金額を確定する

- **事前条件**: 申込受付から収納依頼が到着し、業務状態が「収納手段確定待ち」。引受査定で特別条件が付与されている場合は条件反映後の金額が参照可能
- **事後条件**: 商品種別・チャネル・申込条件で許容される収納手段(口座振替・クレジットカード・振込・コンビニ払込・現金)と確定金額が定まり、業務状態が「収納依頼中」になる。許容されない手段が選択された場合は確定せず、選択可能な手段を画面に返す

```mermaid
sequenceDiagram
    autonumber
    actor act5 as 申込人(契約者)<br/>ACT-5
    participant sys as 個人保険新契約システム
    participant ext9 as 決済サービス<br/>EXT-9

    act5->>sys: 保険料払込画面で収納手段を選択し<br/>「この方法で支払う」ボタンをクリック
    activate sys

    opt FUNC-25: 収納手段・金額確定機能
        sys->>sys: 商品種別・チャネル・申込条件から許容される<br/>収納手段を判定し、確定プラン・払込方法・<br/>特別条件を反映した収納金額を算定

        break 選択された収納手段が当該申込では許容されない
            sys->>sys: 業務状態を「収納手段確定待ち」のまま保持し、<br/>選択不可と判定した理由を記録
            sys-->>act5: 保険料払込画面に選択できない旨と、<br/>選択可能な収納手段の一覧を表示
        end

        sys->>ext9: 確定した収納手段・収納金額と<br/>処理識別を渡して収納を依頼
        activate ext9
        ext9-->>sys: 収納依頼の受付結果<br/>(受付番号・手段別の成立条件)
        deactivate ext9

        break 収納依頼が不達・タイムアウト
            sys->>sys: 業務状態を「収納手段確定待ち」のまま保持し、<br/>依頼不達の発生日時を記録
            sys-->>act5: 保険料払込画面に手続きが未完了である旨と、<br/>時間をおいて再操作する案内を表示
        end

        sys->>sys: 業務状態を「収納依頼中」へ更新し、<br/>確定した収納手段・収納金額・処理識別を記録
        sys-->>act5: 保険料払込画面に受付内容(収納手段・金額・<br/>払込期限)と、以降の手続きの案内を表示
        Note over sys: 参照: UC-68 業務通知を配信する
    end

    deactivate sys
```
