# UC-3: 意向情報取得の本人同意を取得する

- **事前条件**: 意向の業務状態が「聴取中」で、取得・利用目的を明示すべき意向情報が入力されている
- **事後条件**: 意向情報の取得・利用目的が本人に明示され、同意の取得日時・同意範囲・同意者が同意履歴として記録される。同意が得られない場合や取得後に撤回された場合は、その事実と時点を記録し、意向を確定・引き渡しできない旨を画面に返す

```mermaid
sequenceDiagram
    autonumber
    actor act1_2 as 募集人<br/>ACT-1・ACT-2
    actor act5 as 申込人(契約者)<br/>ACT-5
    participant sys as 個人保険新契約システム

    act1_2->>sys: 意向把握画面で<br/>「取得・利用目的を説明して同意を取得」<br/>ボタンをクリック
    activate sys

    opt FUNC-71: 本人同意管理機能
        sys-->>act5: 同意取得画面に意向情報の取得・利用目的、<br/>同意範囲、撤回方法を表示
        act5->>sys: 同意取得画面で「同意する」ボタンをクリック
        sys->>sys: 同意の取得日時・同意範囲・同意者を<br/>同意履歴として記録

        break 同意が得られない・取得後に撤回された
            sys->>sys: 意向の業務状態を「聴取中」のまま保持し、<br/>不同意または撤回の事実と時点を記録
            sys-->>act1_2: 意向把握画面に同意が未取得である旨と、<br/>意向を確定・引き渡しできない旨を表示
        end

        sys-->>act1_2: 意向把握画面に同意取得済みである旨と、<br/>意向確定へ進む導線を表示
    end

    deactivate sys
```
