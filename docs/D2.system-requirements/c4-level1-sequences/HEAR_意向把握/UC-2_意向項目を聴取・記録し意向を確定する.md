# UC-2: 意向項目を聴取・記録し意向を確定する

- **事前条件**: 意向の業務状態が「聴取中」で、募集権限が確認済み
- **事後条件**: 加入目的・希望保障・保険料予算・既契約状況・家族構成・職業の主要意向項目が網羅され、本人同意が取得済みの状態で業務状態が「意向確定」になる。未充足項目がある場合や同意が未取得の場合は「聴取中」のまま保持し、未充足項目と再聴取の導線を画面に返す

```mermaid
sequenceDiagram
    autonumber
    actor act1_2 as 募集人<br/>ACT-1・ACT-2
    participant sys as 個人保険新契約システム

    act1_2->>sys: 意向把握画面で加入目的・希望保障・保険料予算・<br/>既契約状況・家族構成・職業を入力し<br/>「入力内容を保存」ボタンをクリック
    activate sys

    opt FUNC-2: 意向項目入力・記録機能
        sys->>sys: 対面/非対面で同一の項目定義に沿って<br/>入力内容を記録し、未充足の意向項目を検知
        sys-->>act1_2: 意向把握画面に入力済み項目と<br/>未充足の意向項目を表示
    end

    deactivate sys

    act1_2->>sys: 意向把握画面で「意向を確定」ボタンをクリック
    activate sys

    opt FUNC-3: 意向確定機能
        sys->>sys: 主要意向項目の充足状況と、<br/>意向情報取得に対する本人同意の<br/>取得状況を検証

        break 主要意向項目が未充足・取得不能項目あり
            sys->>sys: 意向の業務状態を「聴取中」のまま保持し、<br/>取得不能項目と理由を記録
            sys-->>act1_2: 意向把握画面に未充足項目と、<br/>再聴取または募集中断の導線を表示
        end

        break 意向情報取得の本人同意が未取得・撤回済み
            sys->>sys: 意向の業務状態を「聴取中」のまま保持し、<br/>同意未取得のため確定できない旨を記録
            sys-->>act1_2: 意向把握画面に本人同意が必要である旨と、<br/>同意取得へ進む導線を表示
            Note over sys: 参照: UC-3 意向情報取得の本人同意を取得する
        end

        sys->>sys: 意向の業務状態を「意向確定」へ更新し、<br/>確定した意向内容・確定日時・募集人を記録
        sys-->>act1_2: 意向把握画面に意向が確定した旨と、<br/>証跡連携・引き渡しへ進む導線を表示
    end

    deactivate sys
```
