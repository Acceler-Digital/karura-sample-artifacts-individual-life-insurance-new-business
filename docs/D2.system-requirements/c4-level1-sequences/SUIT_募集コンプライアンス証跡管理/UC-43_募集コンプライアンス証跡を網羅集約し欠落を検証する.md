# UC-43: 募集コンプライアンス証跡を網羅集約し欠落を検証する

- **事前条件**: 意向把握・設計書作成・申込受付・告知受付の各工程から証跡イベントが到達しており、案件単位で必須証跡の定義が参照可能
- **事後条件**: 案件単位で必須証跡の網羅性が検証され、欠落がなければ証跡セットが確定・保全された状態になる。欠落を検知した場合は当該案件を不備として扱い関係工程・コンプライアンス部へ通知する。遅延到達は欠落扱いとせず、受領時刻と事象発生時刻を区別して保全する

```mermaid
sequenceDiagram
    autonumber
    actor act15 as コンプライアンス部<br/>ACT-15
    participant sys as 個人保険新契約システム

    act15->>sys: 証跡集約画面で対象案件を選び<br/>「証跡の網羅性を検証」ボタンをクリック
    activate sys

    opt FUNC-43: 募集証跡集約・欠落検証機能
        sys->>sys: 意向把握・設計書作成・申込受付・告知受付から<br/>受領した証跡イベントを案件単位に集約し、<br/>受領時刻と事象発生時刻を区別して保全

        break 必須証跡が未受領で欠落
            sys->>sys: 当該案件を不備として記録し、<br/>欠落した証跡種別と発生元工程を<br/>関係工程・コンプライアンス部へ通知
            sys-->>act15: 証跡集約画面に欠落した証跡種別・発生元工程と、<br/>後続工程の進行可否の判断材料を表示
        end

        sys->>sys: 証跡セットを確定して改ざん不能保存へ封入し、<br/>保存期間の管理を開始
        sys-->>act15: 証跡集約画面に網羅性を満たした旨と、<br/>保全した証跡の一覧・保存期間を表示
    end

    deactivate sys
```
