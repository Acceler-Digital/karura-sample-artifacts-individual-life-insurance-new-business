# UC-14: 告知を本人入力する

- **事前条件**: 申込確定を受けて告知受付が起動し、告知の業務状態が「告知依頼済」で被保険者本人の入力経路が用意されている
- **事後条件**: 健康状態・既往歴・現在の傷病・職業 等の告知事項が被保険者本人の経路で記録され、必須項目の欠落と告知事項間の矛盾がない状態で業務状態が「入力完了」になる。第三者による代理入力・改変は受け付けず、疑い事象を証跡として保全する

```mermaid
sequenceDiagram
    autonumber
    actor act6 as 被保険者<br/>ACT-6
    participant sys as 個人保険新契約システム

    act6->>sys: 告知入力画面で健康状態・既往歴・現在の傷病・<br/>職業 等の告知事項を入力し<br/>「入力内容を保存」ボタンをクリック
    activate sys

    opt FUNC-15: 告知本人入力機能
        sys->>sys: 入力経路が被保険者本人の経路であることを確認

        break 募集人・申込人 等の第三者経路からの入力・改変
            sys->>sys: 入力を受け付けず、第三者の介入試行を<br/>証跡として保全してコンプライアンス部の<br/>確認へ回付
            sys-->>act6: 告知入力画面に被保険者本人以外は<br/>入力できない旨を表示
            Note over sys: 参照: UC-46 疑義案件をレビュー対象として連携する
        end

        sys->>sys: 告知事項を記録し、必須告知事項の欠落と<br/>告知事項間の明らかな矛盾を検知

        break 必須告知事項の欠落・告知事項間の矛盾あり
            sys->>sys: 告知の業務状態を「入力中」のまま保持し、<br/>不足・矛盾の箇所を記録
            sys-->>act6: 告知入力画面に不足・矛盾の箇所と<br/>訂正方法を表示
        end

        sys->>sys: 告知の業務状態を「入力完了」へ更新し、<br/>入力日時・入力者(被保険者)を記録
        sys-->>act6: 告知入力画面に入力が完了した旨と、<br/>健康情報の取得同意へ進む導線を表示
    end

    deactivate sys
```
