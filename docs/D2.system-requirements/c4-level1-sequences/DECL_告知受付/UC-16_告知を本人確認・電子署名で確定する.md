# UC-16: 告知を本人確認・電子署名で確定する

- **事前条件**: 告知の業務状態が「入力完了」で、健康情報の取得同意が取得済み
- **事後条件**: 被保険者本人が内容を確認し電子署名が取得された状態で告知の業務状態が「告知確定」となり、募集コンプライアンス証跡が記録されたうえで引受査定へ引き渡される。電子署名が取得できない場合は「本人確認中」のまま確定させず、代替の署名取得手段を画面に返す

```mermaid
sequenceDiagram
    autonumber
    actor act6 as 被保険者<br/>ACT-6
    participant sys as 個人保険新契約システム
    participant ext8 as 電子署名サービス<br/>EXT-8

    act6->>sys: 告知内容確認画面で内容を確認し<br/>「告知を確定する」ボタンをクリック
    activate sys

    opt FUNC-16: 告知確定機能
        sys->>sys: 告知事項の網羅性と告知事項間の矛盾有無を<br/>最終確認し、業務状態を「本人確認中」へ更新

        break 告知事項の不足・矛盾あり
            sys->>sys: 告知の業務状態を「入力中」へ戻し、<br/>不足・矛盾の箇所を記録
            sys-->>act6: 告知入力画面に不足・矛盾の箇所と<br/>訂正方法を表示
        end

        sys->>ext8: 告知書への被保険者本人の電子署名の取得結果<br/>(署名者・署名日時・検証結果)を照会
        activate ext8
        ext8-->>sys: 署名済み告知書・署名検証結果
        deactivate ext8

        break 電子署名が未取得・検証不成立・照会不達
            sys->>sys: 告知の業務状態を「本人確認中」のまま保持し、<br/>署名が取得できていない事由を記録
            sys-->>act6: 告知内容確認画面に署名が未取得である旨と、<br/>代替の署名取得手段の案内を表示
            Note over sys: 参照: UC-56 確定文書に本人が電子署名する
        end

        sys->>sys: 告知の業務状態を「告知確定」へ更新し、<br/>確定日時・署名検証結果・被保険者と<br/>本人経路の遵守を証跡として記録
        sys->>sys: 確定告知を引受査定へ欠落なく引き渡し、<br/>業務状態を「引渡済」へ更新
        sys-->>act6: 告知完了画面に告知が確定した旨と、<br/>以降の手続きの案内を表示
        Note over sys: 参照: UC-68 業務通知を配信する
    end

    deactivate sys
```
