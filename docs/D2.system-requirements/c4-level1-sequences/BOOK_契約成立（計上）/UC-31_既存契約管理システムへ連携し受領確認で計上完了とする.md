# UC-31: 既存契約管理システムへ連携し受領確認で計上完了とする

- **事前条件**: 業務状態が「計上処理中」で、契約成立日と計上対象の契約情報が確定している
- **事後条件**: 既存契約管理システムからの計上受領確認をもって業務状態が「計上完了」となり、成立済み契約が保険証券発行へ引き渡される。連携障害・受領未達・データ不整合の場合は「計上保留」として滞留管理し、復旧・是正後に再計上する

```mermaid
sequenceDiagram
    autonumber
    actor act4 as 新契約事務担当者<br/>ACT-4
    participant sys as 個人保険新契約システム
    participant ext3 as 契約管理システム<br/>EXT-3

    act4->>sys: 計上処理一覧画面で対象契約を選び<br/>「計上連携を実行」ボタンをクリック
    activate sys

    opt FUNC-31: 契約管理システム計上連携機能
        sys->>ext3: 成立契約(契約成立日・プラン・特別条件・<br/>責任開始日)と処理識別を渡して計上を連携
        activate ext3
        ext3-->>sys: 計上受領確認(受領有無・不整合の指摘)
        deactivate ext3

        break 連携障害・タイムアウトで受領確認が未達
            sys->>sys: 業務状態を「計上保留」へ更新し、<br/>連携不達の発生日時と再連携の予定を記録
            sys-->>act4: 計上処理詳細画面に計上未完了である旨と、<br/>復旧後に再計上する旨を表示
        end

        break 契約情報・顧客情報の不整合を指摘された
            sys->>sys: 業務状態を「計上保留」へ更新し、<br/>指摘された不整合項目と起因工程を記録
            sys-->>act4: 計上処理詳細画面に不整合項目と、<br/>是正後に再計上する導線を表示
        end

        sys->>sys: 業務状態を「計上完了」へ更新し、受領確認の<br/>日時・処理識別を記録して<br/>成立済み契約を保険証券発行へ引き渡し
        sys-->>act4: 計上処理詳細画面に計上が完了した旨と、<br/>保険証券発行へ進む導線を表示
        Note over sys: 参照: UC-68 業務通知を配信する
    end

    deactivate sys
```
