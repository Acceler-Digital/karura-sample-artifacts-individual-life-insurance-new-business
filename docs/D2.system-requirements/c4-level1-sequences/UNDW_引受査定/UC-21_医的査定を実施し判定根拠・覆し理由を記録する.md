# UC-21: 医的査定を実施し判定根拠・覆し理由を記録する

- **事前条件**: 業務状態が「医的査定待ち」で、告知内容・診査結果・環境査定情報と自動判定の暫定結果が参照可能
- **事後条件**: 引受査定担当者の判断で引受可否区分と特別条件が確定し、適用した引受基準・告知・診査結果・介入理由が判定根拠として記録される。自動判定の暫定結果を覆した場合は覆し理由が必須記録された状態になる

```mermaid
sequenceDiagram
    autonumber
    actor act3 as 引受査定担当者<br/>ACT-3
    participant sys as 個人保険新契約システム

    act3->>sys: 医的査定画面で引受可否区分・特別条件と<br/>判断理由(自動判定を覆す場合は覆し理由)を入力し<br/>「査定結果を確定」ボタンをクリック
    activate sys

    opt FUNC-21: 医的査定機能
        sys->>sys: 業務状態を「医的査定中」として着手日時・<br/>担当者を記録し、入力内容と<br/>自動判定の暫定結果を突合

        break 自動判定の暫定結果を覆す判断で覆し理由が未入力
            sys->>sys: 査定結果を確定させず、<br/>覆し理由が未記録である旨を記録
            sys-->>act3: 医的査定画面に覆し理由の入力が必須である旨と、<br/>入力欄への導線を表示
        end

        sys->>sys: 引受可否区分・特別条件を確定し、適用した<br/>引受基準・告知・診査結果・介入理由<br/>(覆し理由を含む)を判定根拠として記録
        sys->>sys: 業務状態を「査定確定」へ更新し、<br/>判定結果を契約成立(計上)へ引き渡し
        sys-->>act3: 査定案件詳細画面に確定した引受可否区分・<br/>特別条件と判定根拠を表示
        Note over sys: 参照: UC-68 業務通知を配信する
    end

    deactivate sys
```
