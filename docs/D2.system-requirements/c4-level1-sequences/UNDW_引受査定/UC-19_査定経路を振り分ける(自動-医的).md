# UC-19: 査定経路を振り分ける(自動/医的)

- **事前条件**: 告知が確定して査定対象が到着し、業務状態が「査定受付」で、必要な診査結果・環境査定情報が参照可能
- **事後条件**: 引受基準に照合した結果、基準内で完結する案件は「自動判定中」へ、基準外・要医学的判断・告知に疑義がある案件は「医的査定待ち」へ振り分けられ、診査が必要な案件は診査結果が揃うまで確定しない状態になる

```mermaid
sequenceDiagram
    autonumber
    actor act3 as 引受査定担当者<br/>ACT-3
    participant sys as 個人保険新契約システム
    participant ext1 as 商品マスタ管理システム<br/>EXT-1

    act3->>sys: 査定案件一覧画面で対象案件を選び<br/>「査定を開始」ボタンをクリック
    activate sys

    opt FUNC-19: 査定経路振り分け機能
        sys->>ext1: 商品種別・保険金額・被保険者年齢に対応する<br/>査定時点の引受基準(振り分け基準・<br/>診査要否しきい値)を照会
        activate ext1
        ext1-->>sys: 引受基準の内容と適用バージョン
        deactivate ext1

        break 引受基準の参照が不達・タイムアウト
            sys->>sys: 業務状態を「査定受付」のまま保持し、<br/>参照不達の発生日時を記録
            sys-->>act3: 査定案件一覧画面に基準参照が不達である旨と、<br/>回復後に再開する旨を表示
        end

        sys->>sys: 告知内容・診査結果・環境査定情報を<br/>引受基準に照合し、査定経路と診査要否を判定

        break 診査要否しきい値を超過し診査結果が未到着
            sys->>sys: 業務状態を「診査待ち」へ更新し、<br/>必要な診査種別と督促期限を記録
            sys-->>act3: 査定案件詳細画面に診査待ちである旨と、<br/>必要な診査種別・督促期限を表示
        end

        alt 引受基準内で完結する案件
            sys->>sys: 業務状態を「自動判定中」へ更新し、<br/>適用した引受基準バージョンを記録
            sys-->>act3: 査定案件詳細画面に自動判定経路である旨を表示
        else 基準外・要医学的判断・告知に疑義がある案件
            sys->>sys: 業務状態を「医的査定待ち」へ更新し、<br/>医的査定へ回した理由を記録
            sys-->>act3: 査定案件詳細画面に医的査定経路である旨と、<br/>回付理由を表示
        end
    end

    deactivate sys
```
