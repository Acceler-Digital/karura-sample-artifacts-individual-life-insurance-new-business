# UC-20: 自動判定を実行し判定根拠を記録する

- **事前条件**: 業務状態が「自動判定中」で、判定に必要な告知内容・診査結果・環境査定情報が揃っている
- **事後条件**: 引受可否が「可決(無条件)」「特別条件付き可決」「謝絶」「保留(追加情報待ち)」のいずれかに確定し、適用した引受基準バージョンと判定根拠が結論と一体で記録される。機械判定できない組合せの場合は「医的査定待ち」へ切り替える

```mermaid
sequenceDiagram
    autonumber
    actor act3 as 引受査定担当者<br/>ACT-3
    participant sys as 個人保険新契約システム
    participant ext1 as 商品マスタ管理システム<br/>EXT-1

    act3->>sys: 査定案件詳細画面で「自動判定を実行」<br/>ボタンをクリック
    activate sys

    opt FUNC-20: 自動引受判定機能
        sys->>ext1: 査定時点で有効な引受基準<br/>(判定条文・しきい値・特別条件の付与基準)を照会
        activate ext1
        ext1-->>sys: 引受基準の内容と適用バージョン
        deactivate ext1

        sys->>sys: 告知項目・診査結果・環境査定情報(職業・<br/>通算保険金額 等)を引受基準に照合し、<br/>引受可否区分と特別条件の要否を判定

        break 引受基準で機械判定できない組合せ・新規パターン
            sys->>sys: 業務状態を「医的査定待ち」へ更新し、<br/>判断不能となったパターンを<br/>基準チューニングの対象として記録
            sys-->>act3: 査定案件詳細画面に自動判定が不能である旨と、<br/>医的査定へ切り替えた旨を表示
            Note over sys: 参照: UC-21 医的査定を実施し<br/>判定根拠・覆し理由を記録する
        end

        sys->>sys: 引受可否区分を確定し、参照した告知項目・<br/>診査結果・環境査定情報・引受基準の条文と<br/>適用バージョンを判定根拠として結論と一体で記録
        sys->>sys: 業務状態を「査定確定」へ更新し、<br/>判定結果を契約成立(計上)へ引き渡し
        sys-->>act3: 査定案件詳細画面に引受可否区分・特別条件と<br/>判定根拠を表示
        Note over sys: 参照: UC-68 業務通知を配信する
    end

    deactivate sys
```
