# UC-22: 査定イレギュラー案件を収束させる

- **事前条件**: 診査結果の長期未到着・告知内容への疑義・特別条件への申込人不同意 等により、業務状態が「診査待ち」または「査定保留」で滞留している
- **事後条件**: 督促・追加告知依頼・条件再交渉のいずれかにより査定が再開されるか、期限内に情報が揃わない場合は「査定中止」として収束し、後続の契約成立(計上)へ不成立が伝達された状態になる

```mermaid
sequenceDiagram
    autonumber
    actor act3 as 引受査定担当者<br/>ACT-3
    participant sys as 個人保険新契約システム

    act3->>sys: 査定滞留一覧画面で収束対象の案件を選び<br/>「収束処理」ボタンをクリック
    activate sys

    opt FUNC-22: 査定イレギュラー収束管理機能
        sys->>sys: 滞留事由(診査結果未到着・追加告知必要・<br/>特別条件不同意)と滞留日数・督促期限を集約
        sys-->>act3: 査定滞留詳細画面に滞留事由・滞留日数・<br/>督促期限と、収束方法の選択肢を表示

        break 督促期限内で情報到着を待てる
            sys->>sys: 業務状態を滞留時のまま保持し、<br/>督促の実施内容と次回督促期限を記録
            sys-->>act3: 査定滞留詳細画面に督促を記録した旨と、<br/>次回督促期限を表示
            Note over sys: 参照: UC-68 業務通知を配信する
        end

        alt 追加告知・再告知が必要
            sys->>sys: 照会事項を起票して告知受付へ連携し、<br/>業務状態を「査定保留」として回答期限を記録
            sys-->>act3: 査定滞留詳細画面に追加告知を依頼した旨と、<br/>回答期限を表示
        else 期限超過・特別条件に不同意で申込撤回
            sys->>sys: 業務状態を「査定中止」へ更新し、<br/>中止事由・判断者を記録して<br/>契約成立(計上)へ不成立を伝達
            sys-->>act3: 査定滞留詳細画面に査定中止として<br/>収束した旨を表示
        end
    end

    deactivate sys
```
