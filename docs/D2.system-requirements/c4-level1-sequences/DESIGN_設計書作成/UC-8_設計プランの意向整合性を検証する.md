# UC-8: 設計プランの意向整合性を検証する

- **事前条件**: プランの業務状態が「試算済」で、当初意向(保障種類・保障額・保障期間・保険料予算)が参照可能
- **事後条件**: 当初意向と設計プランの乖離有無が判定され、乖離がない場合はプラン確定へ進める状態になる。乖離がある場合は乖離内容を画面に明示し、意向の見直しまたは顧客への説明・合意のいずれかを経るまで申込へ引き渡せない状態を保つ

```mermaid
sequenceDiagram
    autonumber
    actor act1_2 as 募集人<br/>ACT-1・ACT-2
    participant sys as 個人保険新契約システム

    act1_2->>sys: 設計書作成画面で「意向との整合性を検証」<br/>ボタンをクリック
    activate sys

    opt FUNC-8: 意向整合性検証機能
        sys->>sys: 当初意向の保障種類・保障額・保障期間・<br/>保険料予算と設計プランを突合し、<br/>乖離項目を判定

        break 当初意向との乖離あり
            sys->>sys: プランの業務状態を「試算済」のまま保持し、<br/>乖離項目と乖離内容を記録
            sys-->>act1_2: 設計書作成画面に乖離項目・乖離内容と、<br/>意向の見直しまたは顧客説明・合意の<br/>記録導線を表示
            Note over sys: 参照: UC-5 確定済み意向を修正・撤回する
        end

        sys->>sys: 意向整合性の検証結果と検証日時を<br/>プランに記録
        sys-->>act1_2: 設計書作成画面に意向と整合している旨と、<br/>プラン比較提示へ進む導線を表示
    end

    deactivate sys
```
