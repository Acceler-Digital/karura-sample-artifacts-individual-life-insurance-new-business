# UC-9: 複数プランを比較・提示し確定して申込へ引き渡す

- **事前条件**: 意向整合性の検証を終えた設計プランが 1 つ以上あり、顧客へ比較提示できる状態
- **事後条件**: 重要事項(保障内容・保険料・注意喚起事項)の説明事実が情報提供証跡として発生し、顧客が選択した単一プランの業務状態が「プラン確定」を経て「引渡済」になる。証跡連携が不達の場合は提示・確定を完了扱いとしない

```mermaid
sequenceDiagram
    autonumber
    actor act1_2 as 募集人<br/>ACT-1・ACT-2
    participant sys as 個人保険新契約システム

    act1_2->>sys: 設計書作成画面で比較対象プランを選び<br/>「プランを比較提示」ボタンをクリック
    activate sys

    opt FUNC-9: プラン比較提示機能
        sys-->>act1_2: プラン比較画面に複数プランの保障内容・<br/>保険料・注意喚起事項を並べて表示
        sys->>sys: 提示日時・提示プラン・説明した重要事項・<br/>募集人を情報提供証跡として発生させ、<br/>証跡管理へ連携

        break 情報提供証跡の連携が不達
            sys->>sys: 提示を完了扱いとせず、<br/>連携未達の事実と再連携の予定を記録
            sys-->>act1_2: プラン比較画面に提示を完了扱いにできない旨と、<br/>証跡連携の回復後に完了する旨を表示
        end
    end

    deactivate sys

    act1_2->>sys: プラン比較画面で顧客が選択したプランを選び<br/>「このプランで申込」ボタンをクリック
    activate sys

    opt FUNC-10: プラン確定・申込引き渡し機能
        sys->>sys: プランの業務状態を「プラン確定」へ更新し、<br/>確定プラン・確定日時・募集人を記録
        sys->>sys: 確定プランと確定意向を欠落なく申込受付へ<br/>引き渡し、業務状態を「引渡済」へ更新
        sys-->>act1_2: 設計書作成画面にプランを確定し<br/>申込受付へ引き渡した旨と、<br/>申込入力へ進む導線を表示
        Note over sys: 参照: UC-68 業務通知を配信する
    end

    deactivate sys
```
