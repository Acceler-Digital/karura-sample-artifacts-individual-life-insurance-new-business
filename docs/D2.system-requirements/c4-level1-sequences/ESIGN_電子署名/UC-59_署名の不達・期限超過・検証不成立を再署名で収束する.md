# UC-59: 署名の不達・期限超過・検証不成立を再署名で収束する

- **事前条件**: 外部不達・署名依頼の有効期限超過・検証 NG のいずれかが発生し、業務状態が「署名依頼中」「署名失効」「署名無効」のまま滞留している
- **事後条件**: 再署名の依頼により業務状態が「署名依頼中」へ戻るか、一定回数の失効後は業務所管の判断で打ち切りとして収束した状態になる。いずれの場合も収束の事由と経緯が証跡として記録される

```mermaid
sequenceDiagram
    autonumber
    actor act4_1_2 as 新契約事務担当者・募集人<br/>ACT-4・ACT-1・ACT-2
    participant sys as 個人保険新契約システム
    participant ext8 as 電子署名サービス<br/>EXT-8

    act4_1_2->>sys: 署名滞留一覧画面で対象案件を選び<br/>「収束処理」ボタンをクリック
    activate sys

    opt FUNC-59: 署名不達・再署名収束機能
        sys->>sys: 滞留事由(不達・期限超過・検証不成立)と<br/>これまでの失効回数・再依頼回数を集約
        sys-->>act4_1_2: 署名滞留詳細画面に滞留事由・失効回数と、<br/>収束方法の選択肢を表示

        break 業務所管の方針の範囲内で再署名を依頼できる
            sys->>ext8: 対象文書と署名者、新たな有効期限を渡して<br/>再署名を依頼
            activate ext8
            ext8-->>sys: 再署名依頼の受付結果
            deactivate ext8
            sys->>sys: 業務状態を「署名依頼中」へ戻し、<br/>再依頼回数と新たな有効期限を記録
            sys-->>act4_1_2: 署名滞留詳細画面に再署名を依頼した旨と、<br/>新たな有効期限を表示
            Note over sys: 参照: UC-68 業務通知を配信する
        end

        sys->>sys: 一定回数の失効後として打ち切りを記録し、<br/>打ち切り事由・判断者と後続工程への影響を<br/>証跡として保持
        sys-->>act4_1_2: 署名滞留詳細画面に署名手続きを打ち切った旨と、<br/>申込の取り扱いに関する案内を表示
    end

    deactivate sys
```
