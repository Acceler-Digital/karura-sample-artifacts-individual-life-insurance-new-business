# UC-56: 確定文書に本人が電子署名する

- **事前条件**: 署名対象文書(申込書・告知書 等)の内容が確定し、当該文書の取扱い説明・同意が完了していて、業務状態が「署名対象確定」
- **事後条件**: 申込書は申込人、告知書は被保険者という署名者の指定のもとで外部電子署名サービスへ署名依頼が発出され、署名完了により業務状態が「署名済(未検証)」になる。署名者の取り違えや署名後の文書変更が判明した場合は当該署名を無効とし再署名を依頼する

```mermaid
sequenceDiagram
    autonumber
    actor act5_6 as 申込人・被保険者<br/>ACT-5・ACT-6
    participant sys as 個人保険新契約システム
    participant ext8 as 電子署名サービス<br/>EXT-8

    act5_6->>sys: 署名依頼画面で署名対象文書の内容を確認し<br/>「電子署名を行う」ボタンをクリック
    activate sys

    opt FUNC-56: 電子署名機能
        sys->>sys: 署名対象文書が確定済みであることと、<br/>署名者(申込書=申込人/告知書=被保険者)の<br/>指定が正しいことを確認

        break 文書が未確定・署名者の指定が誤っている
            sys->>sys: 署名依頼を発出せず、<br/>未確定の項目または取り違えの内容を記録
            sys-->>act5_6: 署名依頼画面に署名できない旨と、<br/>その理由・是正の案内を表示
        end

        sys->>ext8: 確定文書と署名者の指定、<br/>署名依頼の有効期限を渡して署名を依頼
        activate ext8
        ext8-->>sys: 署名依頼の受付結果と署名完了の通知
        deactivate ext8

        break 署名依頼が不達・有効期限内に署名が完了しない
            sys->>sys: 業務状態を「署名依頼中」または「署名失効」として<br/>保持し、不達・失効の事由と再依頼の要否を記録
            sys-->>act5_6: 署名依頼画面に署名が完了していない旨と、<br/>再度署名を行う導線を表示
            Note over sys: 参照: UC-59 署名の不達・期限超過・<br/>検証不成立を再署名で収束する
        end

        sys->>sys: 業務状態を「署名済(未検証)」へ更新し、<br/>署名対象文書・署名者・署名日時を記録
        sys-->>act5_6: 署名完了画面に署名が完了した旨と、<br/>以降の手続きの案内を表示
    end

    deactivate sys
```
