# UC-57: 真実性措置(タイムスタンプ)付与を外部サービスへ依頼する

- **事前条件**: 業務状態が「署名済(未検証)」で、署名済み文書に対する真実性措置の付与が必要
- **事後条件**: 外部電子署名サービスにより真実性措置(タイムスタンプ等)が付与され、付与結果が記録された状態になる。付与に失敗した場合は署名検証済みへ進めず、再付与または再署名を依頼する。本システムは真実性措置を独自に生成しない

```mermaid
sequenceDiagram
    autonumber
    actor act4 as 新契約事務担当者<br/>ACT-4
    participant sys as 個人保険新契約システム
    participant ext8 as 電子署名サービス<br/>EXT-8

    act4->>sys: 署名管理画面で対象文書を選び<br/>「真実性措置の付与を依頼」ボタンをクリック
    activate sys

    opt FUNC-57: 真実性措置付与機能
        sys->>ext8: 署名済み文書を指定して<br/>真実性措置(タイムスタンプ等)の付与を依頼
        activate ext8
        ext8-->>sys: 付与結果(付与済みの措置情報 / エラー)
        deactivate ext8

        break 真実性措置の付与に失敗
            sys->>sys: 業務状態を「署名済(未検証)」のまま保持し、<br/>付与失敗の事由と再付与・再署名の要否を記録
            sys-->>act4: 署名管理画面に真実性措置が付与できていない旨と、<br/>再付与または再署名の導線を表示
        end

        sys->>sys: 付与された措置情報(付与日時・措置種別)を<br/>証跡として記録し、署名検証へ進める状態にする
        sys-->>act4: 署名管理画面に真実性措置が付与された旨と、<br/>付与日時・措置種別を表示
    end

    deactivate sys
```
