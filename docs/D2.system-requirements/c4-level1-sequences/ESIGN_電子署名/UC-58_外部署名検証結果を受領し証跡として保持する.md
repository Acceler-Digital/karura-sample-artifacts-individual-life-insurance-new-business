# UC-58: 外部署名検証結果を受領し証跡として保持する

- **事前条件**: 署名済み文書に真実性措置が付与され、外部電子署名サービスによる検証結果を受領できる状態
- **事後条件**: 署名者・署名日時・文書の同一性に関する外部サービスの検証結果が証跡として保持され、業務状態が「署名検証済」になる。検証 NG の場合は「署名無効」として再署名の対象とし、改ざんの疑いがある場合はエスカレーションする。本システムは独自の検証アルゴリズムを実装しない

```mermaid
sequenceDiagram
    autonumber
    actor act4 as 新契約事務担当者<br/>ACT-4
    participant sys as 個人保険新契約システム
    participant ext8 as 電子署名サービス<br/>EXT-8

    act4->>sys: 署名管理画面で対象文書を選び<br/>「検証結果を受領」ボタンをクリック
    activate sys

    opt FUNC-58: 署名検証結果受領・保持機能
        sys->>ext8: 署名済み文書の検証結果<br/>(署名者・署名日時・文書の同一性)を照会
        activate ext8
        ext8-->>sys: 検証結果(OK/NG と検証内容)
        deactivate ext8

        break 検証結果が NG(署名と文書の不整合・措置の不備)
            sys->>sys: 業務状態を「署名無効」へ更新し、NG の内容と<br/>原因の切り分け結果を記録。改ざんの疑いがある場合は<br/>コンプライアンス部・CSIRT へエスカレーション
            sys-->>act4: 署名管理画面に署名が無効である旨と、<br/>再署名の導線を表示
            Note over sys: 参照: UC-59 署名の不達・期限超過・<br/>検証不成立を再署名で収束する
        end

        sys->>sys: 業務状態を「署名検証済」へ更新し、<br/>検証結果(署名者・署名日時・文書の同一性)を<br/>証跡として保持
        sys-->>act4: 署名管理画面に検証が成立した旨と、<br/>検証結果の内容を表示
    end

    deactivate sys
```
