# UC-67: 本プロダクトにログインする

- **事前条件**: 利用者種別に対応する認証手段(社内利用者=全社IdP との SSO、代理店募集人=代理店IdP とのフェデレーション、申込人/被保険者=本人認証)が利用できる状態にある
- **事後条件**: 利用者種別に整合する認証強度で本人性が確認され、業務画面を利用できる状態になる。要配慮個人情報を扱う操作を行う場合は多要素認証が完了していることを要件とし、未充足の場合は当該操作へ進ませない

```mermaid
sequenceDiagram
    autonumber
    actor act1_6 as 全直接利用アクター<br/>ACT-1〜6
    participant sys as 個人保険新契約システム

    act1_6->>sys: ログイン画面で利用者種別に応じた認証情報を入力し<br/>「ログイン」ボタンをクリック
    activate sys

    opt FUNC-67: 認証・ログイン機能
        sys->>sys: 利用者種別を判定し、社内利用者は全社IdP との SSO、<br/>代理店募集人は代理店IdP とのフェデレーション、<br/>申込人/被保険者は本人認証で本人性を確認

        break 認証に失敗した
            sys->>sys: 業務画面へ進ませず、<br/>認証失敗の試行を監査対象イベントとして記録
            sys-->>act1_6: ログイン画面に認証できなかった旨と、<br/>再試行・問い合わせの案内を表示
        end

        break 要配慮個人情報を扱う操作で多要素認証が未完了
            sys->>sys: 当該操作を許可せず、<br/>追加認証の要求を記録
            sys-->>act1_6: 追加認証画面に多要素認証が必要である旨と、<br/>認証手段の選択肢を表示
        end

        sys->>sys: 認証成立を記録し、利用者種別に応じた<br/>業務画面の利用を許可
        sys-->>act1_6: 業務トップ画面に利用者種別に応じた<br/>担当業務の一覧を表示
    end

    deactivate sys
```
