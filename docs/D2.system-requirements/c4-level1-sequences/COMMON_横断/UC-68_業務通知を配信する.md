# UC-68: 業務通知を配信する

- **事前条件**: 業務上の節目イベント(申込受付・告知完了・査定結果・収納成立・契約成立・証券発行 等)が発生し、通知対象の利用者種別が特定できる
- **事後条件**: 節目イベントごとに各利用者種別へ業務通知が配信され、配信内容・配信日時・配信先が記録された状態になる。共通方針の配信抑制に該当する通知は配信せず、配信に失敗した通知は再送ポリシーに従って再送される

```mermaid
sequenceDiagram
    autonumber
    actor act1_2_4_5_6 as 募集人・新契約事務担当者・申込人・被保険者<br/>ACT-1・ACT-2・ACT-4・ACT-5・ACT-6
    participant sys as 個人保険新契約システム

    act1_2_4_5_6->>sys: 通知設定画面で受け取る通知の種別・媒体を設定し<br/>「設定を保存」ボタンをクリック
    activate sys

    opt FUNC-68: 業務通知配信機能
        sys->>sys: 発生した節目イベントごとに通知対象の利用者種別・<br/>配信媒体を決定し、共通方針の配信抑制条件に<br/>該当するかを判定

        break 配信抑制条件に該当する
            sys->>sys: 通知を配信せず、抑制した理由と<br/>対象イベントを記録
            sys-->>act1_2_4_5_6: 通知履歴画面に配信を抑制した旨と、<br/>抑制理由を表示
        end

        sys->>sys: 業務通知を配信し、配信内容・配信日時・配信先・<br/>配信結果を記録

        break 配信に失敗した
            sys->>sys: 再送ポリシーに従って再送を予定し、<br/>失敗事由と再送回数を記録
            sys-->>act1_2_4_5_6: 通知履歴画面に配信できなかった旨と、<br/>再送予定を表示
        end

        sys-->>act1_2_4_5_6: 通知履歴画面に配信済みの通知一覧と、<br/>配信日時を表示
    end

    deactivate sys
```
