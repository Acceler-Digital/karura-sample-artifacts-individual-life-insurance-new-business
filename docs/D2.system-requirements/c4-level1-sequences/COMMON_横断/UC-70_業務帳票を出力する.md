# UC-70: 業務帳票を出力する

- **事前条件**: 設計書・申込控え・告知書・保険証券 等の出力対象帳票と、その出力形態(画面表示・PDF 出力・既存帳票発送システム連携)が特定できる
- **事後条件**: 指定された形態で業務帳票が出力され、出力内容・出力日時・出力者が記録された状態になる。物理交付を伴う場合は既存帳票発送システムへの連携結果まで記録する。出力対象のデータが確定していない場合は出力しない

```mermaid
sequenceDiagram
    autonumber
    actor act1_2_4 as 募集人・新契約事務担当者<br/>ACT-1・ACT-2・ACT-4
    participant sys as 個人保険新契約システム
    participant ext5 as 帳票発送システム<br/>EXT-5

    act1_2_4->>sys: 帳票出力画面で帳票種別と出力形態を選び<br/>「出力する」ボタンをクリック
    activate sys

    opt FUNC-70: 業務帳票出力機能
        sys->>sys: 出力対象データが確定していることと、<br/>選択された出力形態が当該帳票で<br/>許容されることを確認

        break 出力対象データが未確定・形態が許容されない
            sys->>sys: 帳票を出力せず、未確定の項目または<br/>許容されない形態を記録
            sys-->>act1_2_4: 帳票出力画面に出力できない旨と、<br/>その理由・是正の導線を表示
        end

        alt 出力形態が画面表示・PDF 出力
            sys-->>act1_2_4: 帳票プレビュー画面に帳票を表示し、<br/>PDF として保存する導線を表示
        else 出力形態が既存帳票発送システム連携
            sys->>ext5: 帳票データ・送付先と処理識別を渡して<br/>印刷・封入・郵送を連携
            activate ext5
            ext5-->>sys: 発送連携の受領確認
            deactivate ext5
            sys-->>act1_2_4: 帳票出力画面に発送を連携した旨と、<br/>受領確認の状況を表示
        end

        sys->>sys: 出力した帳票種別・出力形態・出力日時・出力者を<br/>記録
    end

    deactivate sys
```
