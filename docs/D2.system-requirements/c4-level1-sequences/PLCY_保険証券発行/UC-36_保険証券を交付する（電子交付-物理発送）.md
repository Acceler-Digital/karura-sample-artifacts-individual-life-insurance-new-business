# UC-36: 保険証券を交付する(電子交付/物理発送)

- **事前条件**: 業務状態が「証券データ生成済」で、契約者の選択・同意・チャネル・商品条件に基づく交付方法(電子交付/物理交付)が確定している
- **事後条件**: 電子交付は契約者の受領可能状態の確立をもって、物理交付は既存帳票発送システムへの発送連携の受領確認をもって業務状態が「交付完了」になる。発送連携依頼のみでは交付完了とせず、連携障害時は「交付保留」として復旧後に冪等に再連携する

```mermaid
sequenceDiagram
    autonumber
    actor act4 as 新契約事務担当者<br/>ACT-4
    actor act5 as 申込人(契約者)<br/>ACT-5
    participant sys as 個人保険新契約システム
    participant ext5 as 帳票発送システム<br/>EXT-5

    act4->>sys: 証券交付画面で対象契約を選び<br/>「証券を交付」ボタンをクリック
    activate sys

    opt FUNC-36: 証券交付機能(電子交付/物理発送)
        alt 交付方法が電子交付
            sys-->>act5: 証券閲覧画面に保険証券を本人が閲覧できる<br/>状態で公開し、閲覧の案内を表示
            sys->>sys: 契約者の受領可能状態が確立したことを確認し、<br/>確立日時を交付完了の判定根拠として記録

            break 一定期間内に受領可能状態が確立しない
                sys->>sys: 交付未完了のまま保持し、未確立の日数と<br/>物理交付への切替判断の要否を記録
                sys-->>act4: 証券交付詳細画面に受領未確立である旨と、<br/>物理交付への切替導線を表示
            end
        else 交付方法が物理交付
            sys->>ext5: 証券データ・送付先と処理識別を渡して<br/>印刷・封入・郵送の発送を連携
            activate ext5
            ext5-->>sys: 発送連携の受領確認
            deactivate ext5

            break 発送連携が障害・不達で受領確認が未達
                sys->>sys: 業務状態を「交付保留」へ更新し、<br/>不達日時と冪等な再連携の予定を記録
                sys-->>act4: 証券交付詳細画面に交付が未完了である旨と、<br/>復旧後に再連携する旨を表示
            end
        end

        sys->>sys: 業務状態を「交付完了」へ更新し、<br/>交付方法・交付完了の判定根拠・処理識別を記録
        sys-->>act4: 証券交付詳細画面に交付が完了した旨と、<br/>交付方法・完了日時を表示
        Note over sys: 参照: UC-68 業務通知を配信する
    end

    deactivate sys
```
