# UC-35: 証券データを確定契約内容と差異なく生成する

- **事前条件**: 計上完了済みの契約が業務状態「発行待ち」で到着し、確定契約内容(契約者・被保険者・受取人・プラン・保険金額・保険料・払込方法・責任開始日・特別条件)が参照可能
- **事後条件**: 確定契約内容と差異のない証券データが生成され、業務状態が「証券データ生成済」になる。契約内容との不整合を検知した場合、または発行前に契約取消が判明した場合は発行・交付せず、是正または発行停止の証跡を保全する

```mermaid
sequenceDiagram
    autonumber
    actor act4 as 新契約事務担当者<br/>ACT-4
    participant sys as 個人保険新契約システム

    act4->>sys: 証券発行待ち一覧画面で対象契約を選び<br/>「証券データを生成」ボタンをクリック
    activate sys

    opt FUNC-35: 証券データ生成機能
        sys->>sys: 計上完了状態と、クーリングオフ・申込錯誤 等による<br/>契約取消の有無を確認

        break 発行前に契約取消が判明
            sys->>sys: 証券を生成・交付せず、<br/>発行停止の事由と判断日時を証跡として保全
            sys-->>act4: 証券発行詳細画面に発行を停止した旨と、<br/>取消事由を表示
        end

        sys->>sys: 確定契約内容から証券データを生成し、<br/>生成内容と確定契約内容を突合して<br/>差異の有無を検証

        break 証券データと確定契約内容に不整合あり
            sys->>sys: 業務状態を「発行待ち」のまま保持し、<br/>不整合項目と起因工程を記録
            sys-->>act4: 証券発行詳細画面に不整合項目と、<br/>是正後に再生成する導線を表示
        end

        sys->>sys: 業務状態を「証券データ生成済」へ更新し、<br/>生成日時・生成内容・処理識別を記録
        sys-->>act4: 証券発行詳細画面に生成した証券データの内容と、<br/>交付へ進む導線を表示
    end

    deactivate sys
```
