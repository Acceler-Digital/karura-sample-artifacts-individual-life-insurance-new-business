# UC-42: 個人情報の開示・訂正・利用停止請求に対応する

- **事前条件**: 本人から法令に基づく保有個人情報の開示・訂正・利用停止の請求があり、本人性が確認できる状態にある
- **事後条件**: 請求内容が受け付けられ、対応期限とともに業務手続きへ回付された状態になる。手続き進行中の案件がある場合は影響有無が判定され関係工程へ連絡される。本人性が確認できない場合は請求を受け付けない

```mermaid
sequenceDiagram
    autonumber
    actor act5_6 as 申込人・被保険者<br/>ACT-5・ACT-6
    participant sys as 個人保険新契約システム

    act5_6->>sys: 個人情報請求画面で請求種別(開示・訂正・<br/>利用停止)と対象情報を入力し<br/>「請求する」ボタンをクリック
    activate sys

    opt FUNC-42: 個人情報開示・訂正・利用停止対応機能
        sys->>sys: 請求者の本人性と請求対象の保有状況を確認

        break 本人性が確認できない・対象情報を保有していない
            sys->>sys: 請求を受け付けず、受付不可の理由を記録
            sys-->>act5_6: 個人情報請求画面に受け付けられない旨と、<br/>その理由・問い合わせ先を表示
        end

        sys->>sys: 請求を受け付けて受付日時・請求種別・対象情報と<br/>法令に基づく対応期限を記録

        break 手続き進行中の案件に影響する請求
            sys->>sys: 進行中案件への影響有無を判定し、<br/>影響する工程(申込受付・告知受付 等)へ連絡
            sys-->>act5_6: 個人情報請求画面に請求を受け付けた旨と、<br/>進行中の手続きへの影響・対応期限を表示
        end

        sys-->>act5_6: 個人情報請求画面に請求を受け付けた旨と、<br/>受付番号・対応期限を表示
    end

    deactivate sys
```
