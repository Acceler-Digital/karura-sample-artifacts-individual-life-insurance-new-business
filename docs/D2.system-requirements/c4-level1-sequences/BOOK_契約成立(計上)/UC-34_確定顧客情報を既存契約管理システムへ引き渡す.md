# UC-34: 確定顧客情報を既存契約管理システムへ引き渡す

- **事前条件**: 契約成立条件が充足し、引き渡し対象となる申込人・被保険者・受取人の属性・関係性が確定している
- **事後条件**: 確定顧客情報が既存契約管理システムへ引き渡され、保全・継続収納業務へ引き継がれた状態になる。不達の場合は引き渡し対象を確定状態のまま保全し、引き渡し未了として追跡して回復後に再連携する

```mermaid
sequenceDiagram
    autonumber
    actor act4 as 新契約事務担当者<br/>ACT-4
    participant sys as 個人保険新契約システム
    participant ext3 as 契約管理システム<br/>EXT-3

    act4->>sys: 計上処理詳細画面で「顧客情報を引き渡す」<br/>ボタンをクリック
    activate sys

    opt FUNC-34: 確定顧客情報引き渡し機能
        sys->>sys: 申込人・被保険者・受取人の属性と関係性<br/>(続柄・指定割合)が確定していることを確認

        break 確定していない属性・関係性がある
            sys->>sys: 引き渡しを行わず、未確定の項目と<br/>その所管工程を記録
            sys-->>act4: 計上処理詳細画面に引き渡しできない旨と、<br/>未確定項目・是正の導線を表示
        end

        sys->>ext3: 確定した申込人・被保険者・受取人の属性・<br/>関係性と処理識別を渡して引き渡しを連携
        activate ext3
        ext3-->>sys: 引き渡しの受領確認
        deactivate ext3

        break 引き渡しが不達・受領確認が未達
            sys->>sys: 引き渡し対象を確定状態のまま保全し、<br/>引き渡し未了として不達日時・再連携予定を記録
            sys-->>act4: 計上処理詳細画面に引き渡しが未了である旨と、<br/>回復後に再連携する旨を表示
        end

        sys->>sys: 引き渡し完了を記録し、<br/>保全・継続収納業務への引き継ぎ済みとする
        sys-->>act4: 計上処理詳細画面に顧客情報の引き渡しが<br/>完了した旨を表示
    end

    deactivate sys
```
