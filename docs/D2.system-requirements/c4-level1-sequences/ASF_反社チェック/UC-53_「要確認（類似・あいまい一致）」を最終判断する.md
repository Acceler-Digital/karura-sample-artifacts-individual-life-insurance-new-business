# UC-53: 「要確認(類似・あいまい一致)」を最終判断する

- **事前条件**: 外部反社チェックサービスから「要確認(類似・あいまい一致)」の応答があり、業務状態が「要確認」で業務所管の判断待ちになっている
- **事後条件**: 業務所管の最終判断により業務状態が「非該当」または「該当確定」に確定し、判断根拠と結果が証跡として保持された状態になる。判断が完了するまで契約成立扱いにしない

```mermaid
sequenceDiagram
    autonumber
    actor act15 as コンプライアンス部<br/>ACT-15
    participant sys as 個人保険新契約システム

    act15->>sys: 反社要確認一覧画面で対象案件を選び<br/>判断結果(非該当/該当)と判断根拠を入力して<br/>「最終判断を確定」ボタンをクリック
    activate sys

    opt FUNC-53: 反社要確認最終判断機能
        sys->>sys: 外部サービスの照合結果と一致箇所を<br/>判断材料として確認

        break 判断根拠が未入力
            sys->>sys: 最終判断を確定させず、<br/>根拠が未記録である旨を記録
            sys-->>act15: 反社要確認詳細画面に判断根拠の入力が<br/>必須である旨を表示
        end

        alt 業務所管が非該当と判断
            sys->>sys: 業務状態を「非該当」へ更新し、<br/>判断根拠・判定日時・判定主体を証跡として保持
            sys-->>act15: 反社要確認詳細画面に非該当として確定した旨と、<br/>手続きが再開できる旨を表示
        else 業務所管が該当と判断
            sys->>sys: 業務状態を「該当確定」へ更新し、<br/>判断根拠・判定日時・判定主体を証跡として保持
            sys-->>act15: 反社要確認詳細画面に該当確定とした旨と、<br/>進行停止・エスカレーションへ進む導線を表示
            Note over sys: 参照: UC-54 反社該当確定時に進行停止し<br/>エスカレーションする
        end
    end

    deactivate sys
```
