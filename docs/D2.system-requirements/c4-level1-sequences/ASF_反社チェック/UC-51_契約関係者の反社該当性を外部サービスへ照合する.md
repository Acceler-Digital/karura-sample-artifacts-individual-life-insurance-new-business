# UC-51: 契約関係者の反社該当性を外部サービスへ照合する

- **事前条件**: 申込受付で申込人・被保険者・受取人 等の契約関係者が確定し、業務状態が「未依頼」
- **事後条件**: 外部反社チェックサービスの照合結果に依拠して業務状態が「非該当」「要確認」「照合保留」のいずれかに振り分けられ、依頼内容・応答・再実行履歴が証跡として保持された状態になる。不達の場合は再依頼で業務を継続し、チェック完了まで契約成立へ進めない

```mermaid
sequenceDiagram
    autonumber
    actor act1_2_4 as 募集人・新契約事務担当者<br/>ACT-1・ACT-2・ACT-4
    participant sys as 個人保険新契約システム
    participant ext7 as 反社チェックサービス<br/>EXT-7

    act1_2_4->>sys: 反社チェック画面で対象案件を選び<br/>「反社照合を依頼」ボタンをクリック
    activate sys

    opt FUNC-51: 反社照合機能
        sys->>ext7: 申込人・被保険者・受取人の氏名・生年月日 等と<br/>処理識別を渡して反社該当性の照合を依頼
        activate ext7
        ext7-->>sys: 照合結果(非該当/要確認/該当)と判定日時
        deactivate ext7

        break 照合が不達・タイムアウト
            sys->>sys: 業務状態を「照合保留」へ更新し、<br/>不達日時と再依頼手順による再実行の予定を記録
            sys-->>act1_2_4: 反社チェック画面に照合が未完了である旨と、<br/>チェック完了まで契約成立が保留となる旨を表示
        end

        break 照合結果が「該当」「要確認(類似・あいまい一致)」
            sys->>sys: 業務状態を「要確認」へ更新し、<br/>照合結果・判定日時・判定主体を証跡として保持して<br/>業務所管の最終判断へ回付
            sys-->>act1_2_4: 反社チェック画面に業務所管の判断待ちである旨を<br/>表示(判定理由は限定開示のため非表示)
            Note over sys: 参照: UC-53 「要確認(類似・あいまい一致)」を<br/>最終判断する
        end

        sys->>sys: 業務状態を「非該当」へ更新し、照合方法・<br/>判定結果・判定日時・判定主体と<br/>再実行履歴を証跡として保持
        sys-->>act1_2_4: 反社チェック画面にチェックが完了した旨と、<br/>以降の手続きの案内を表示
    end

    deactivate sys
```
